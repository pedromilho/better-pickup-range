# Better Pickup Range

A Hytale mod that lets you adjust your item pickup radius with a live third-person preview. The preview can stay visible after you close the panel.

## Install and use

1. Download `BetterPickupRange.jar` from the [latest release](https://github.com/pedromilho/better-pickup-range/releases/latest). Requires Hytale 0.7.6.
2. Put the file in your Hytale `Mods` folder and enable the mod for your world.
3. Run `/pickuprange`, adjust the radius, and select **Apply**.
